# 🌕 ลอยกระทงออนไลน์ (Loy Krathong Online)

เว็บลอยกระทงออนไลน์แบบเรียลไทม์ ให้คุณเลือกตกแต่งกระทง เขียนคำอธิษฐานขอขมาพระแม่คงคา จุดพลุ ปล่อยโคมลอย และร่วมลอยกระทงไปพร้อมกับทุกคนได้ทั้งบนคอมพิวเตอร์และมือถือ 🪷

## ✨ จุดเด่นและฟีเจอร์สำหรับผู้ใช้งาน

### 1. ตกแต่งกระทงในแบบของคุณ
กดปุ่ม **`🪷 สร้างกระทง`** เพื่อออกแบบกระทงพร้อมดูตัวอย่างแบบสดๆ ได้ตามใจชอบ:
- **ฐานกระทง 8 แบบ:** ใบตองจับจีบ, กลีบบัว, กะลามะพร้าว, ขนมปังรูปเต่า, น้ำแข็ง, ไม้ไผ่สาน, เรือหงส์ทอง และเปลือกข้าวโพด
- **ดอกไม้ประดับ 8 แบบ:** ดอกดาวเรือง, ดอกกล้วยไม้, ดอกกุหลาบ, ดอกบัวหลวง, ดอกมะลิ, ดอกบานไม่รู้โรย, ดอกทานตะวัน และดอกซากุระ
- **สีเทียนและธูป:** เทียน 5 สี (สีทอง, สีแดง, สีฟ้า, สีเขียว, สีม่วง) พร้อมปุ่มเลือกปักหรือไม่ปักธูป 3 ดอก
- **เหรียญ / พลอยมงคล 4 แบบ:** เหรียญทอง, เหรียญเงิน, พลอยมงคล หรือไม่ใส่
- **ของประดับพิเศษ 4 แบบ:** เรียบง่าย, พวงมาลัยดอกรัก, ร่มกระดาษล้านนา และธงฉัตรทองคู่
- **สุ่มตกแต่งทันใจ:** กดปุ่ม **`🎲 สุ่มตกแต่งกระทง`** เพื่อสุ่มจับคู่ลวดลายสวยๆ ให้โดยอัตโนมัติ
- **เขียนคำอธิษฐานง่ายขึ้น:** ใส่ชื่อได้สูงสุด 40 ตัวอักษร (หากเว้นว่างจะแสดงเป็น `"ผู้ไม่ประสงค์ออกนาม"`) และเขียนคำอธิษฐานได้สูงสุด 250 ตัวอักษร พร้อมปุ่มคำอธิษฐานสำเร็จรูป 4 หมวด (สุขภาพแข็งแรง, การงานและการเงิน, ความรัก และการเรียน)

### 2. บรรยากาศแม่น้ำและท้องฟ้าคืนวันเพ็ญ
- ท้องฟ้ายามค่ำคืนพร้อมพระจันทร์เต็มดวง แถบทางช้างเผือกจางๆ เมฆลอยต้องแสงจันทร์ ดาวกะพริบเบาๆ และดาวตกเป็นระยะ
- ฉากริมน้ำสไตล์ไทย ทั้งทิวเขา วัดไทย พระเจดีย์ ศาลาท่าน้ำเรืองแสงไฟอุ่น ต้นมะพร้าวโอนเอน หิ่งห้อย เรือพายติดตะเกียง และแนวตลิ่งด้านหน้า
- กระทงไหลไปตามสายน้ำอย่างนุ่มนวลพร้อมแสงเทียนกะพริบ เงาสะท้อนบนผิวน้ำ และระลอกคลื่น โดยกระทงที่คุณเพิ่งลอยจะปรากฏให้เห็นทันทีพร้อมป้าย **`(ของคุณ)`**

### 3. ร่วมลอยและส่งกำลังใจแบบเรียลไทม์
- ดูจำนวนผู้ที่กำลังออนไลน์และยอดกระทงทั้งหมดที่ลอยไปแล้วได้แบบเรียลไทม์
- กระทงใบใหม่จากผู้ใช้งานคนอื่นจะลอยเข้ามาในแม่น้ำบนหน้าจอของทุกคนทันที
- **อ่านคำอธิษฐาน & ส่งกำลังใจ:** คลิกหรือแตะที่กระทงในแม่น้ำ หรือเปิดจากปุ่ม **`📜 คำอธิษฐาน`** เพื่อดูคำอธิษฐานของแต่ละคนและกด **`❤️ ส่งกำลังใจ`** ให้กันได้

### 4. พลุ โคมลอย เสียงบรรยากาศ และ Easter Egg
- **จุดพลุฉลอง:** กดปุ่ม **`🎆 จุดพลุ`** หรือคลิกตำแหน่งใดก็ได้บนท้องฟ้าเพื่อจุดพลุให้ทุกคนเห็นพร้อมกัน
- **ปล่อยโคมลอยสุ่มหน้าตา:** กดปุ่ม **`🏮 ปล่อยโคม`** เพื่อปล่อยโคมลอยขึ้นฟ้า โดยโคมแต่ละดวงจะสุ่มหน้าตาทั้งรูปทรง 5 แบบ (ทรงยี่เป็ง, ทรงกระบอก, ทรงบัว, ทรงเพชร, ทรงหัวใจ), โทนสี 5 สี, ลวดลาย 4 แบบ และพู่ห้อยด้านล่าง
- **เสียงบรรยากาศ:** เปิดเสียงไว้ให้เป็นค่าเริ่มต้น ทั้งเสียงสายน้ำไหลคลอ เสียงกระดิ่ง เสียงน้ำกระเซ็น เสียงปล่อยโคม เสียงส่งกำลังใจ และเสียงพลุ
- **✈️💥 Easter Egg (โคมลอยชนเครื่องบิน):** มีเครื่องบินบินผ่านท้องฟ้าเป็นระยะ (หรือกดปุ่ม **`P`** บนคีย์บอร์ดเพื่อเรียกเครื่องบินทันที) หากโคมลอยขึ้นไปชนหรือคลิกโดนตัวเครื่องบิน จะเกิดควันไฟ ดิ่งตกลงแม่น้ำพร้อมเสียงไซเรน น้ำกระจาย และแถบข่าวด่วนให้ทุกคนเห็นพร้อมกัน

## 🎮 วิธีใช้งานและปุ่มควบคุม

| การกระทำ | วิธีใช้งาน |
| :--- | :--- |
| **สร้างและลอยกระทง** | กดปุ่ม `🪷 สร้างกระทง` (มุมขวาบนบนคอมพิวเตอร์ หรือแถบปุ่มด้านล่างบนมือถือ) ตกแต่ง เขียนคำอธิษฐาน แล้วกด `🌕 อธิษฐานและลอยกระทง` |
| **ดูรายการคำอธิษฐานทั้งหมด** | กดปุ่ม `📜 คำอธิษฐาน` (`📜` บนมือถือ) เพื่อไล่ดูคำอธิษฐานของกระทงในสายน้ำ |
| **อ่านคำอธิษฐาน / ส่งกำลังใจ** | คลิกหรือแตะที่กระทงในแม่น้ำ หรือเลือกจากรายการคำอธิษฐาน แล้วกด `❤️ ส่งกำลังใจ` |
| **จุดพลุ** | กดปุ่ม `🎆 จุดพลุ` (`🎆` บนมือถือ) หรือคลิกตำแหน่งใดก็ได้บนท้องฟ้า |
| **ปล่อยโคมลอย** | กดปุ่ม `🏮 ปล่อยโคม` (`🏮` บนมือถือ) |
| **เปิด/ปิดเสียง** | กดปุ่ม `🔊` / `🔇` มุมขวาบนเพื่อปิดหรือเปิดเสียงบรรยากาศ |
| **เรียกเครื่องบิน (Easter Egg)** | กดปุ่ม **`P`** บนคีย์บอร์ด (เมื่อไม่ได้พิมพ์ข้อความหรือเปิดหน้าต่างอยู่) แล้วลองปล่อยโคมให้ชนหรือคลิกที่เครื่องบิน |
| **ปิดหน้าต่างที่เปิดอยู่** | กดปุ่ม **`Esc`** บนคีย์บอร์ด หรือกดปุ่ม `×` / พื้นที่ว่างนอกกล่อง |

- เว็บไซต์ตั้งค่า **เปิดเสียงบรรยากาศไว้เป็นค่าเริ่มต้น**
- หากเปิดหน้าเว็บขึ้นมาแล้วไม่ได้ยินเสียงในทันที มักเกิดจากเบราว์เซอร์จำกัดการเล่นเสียงอัตโนมัติก่อนมีการโต้ตอบ เพียงคลิก แตะหน้าจอ หรือกดปุ่มใดๆ ครั้งแรก ระบบจะปลดล็อกเสียงให้ทำงานทันที (หรือกดปุ่ม `🔊` / `🔇` มุมขวาบนเพื่อสลับเปิด-ปิดได้ตามต้องการ)
